# TruthTableExcelFileCreation

Консольная утилита на C#: по логическому выражению генерирует таблицу истинности и сохраняет её в Excel-файл.

## Что делает

Принимает логическое выражение, строит для него таблицу истинности и экспортирует результат в `.xlsx` через библиотеку **ClosedXML**.

## Технологии

- C# / .NET
- ClosedXML (работа с Excel)
- Работа с файловой системой
- Парсинг и вычисление логических выражений

## Как запустить

```bash
git clone https://github.com/BraveLittleMagician/TruthTableExcelFileCreation.git
cd TruthTableExcelFileCreation
dotnet run
```

На выходе создаётся `.xlsx`-файл с таблицей истинности.
